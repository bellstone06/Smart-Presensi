Backup Semua Data (Unduh Cadangan)

Unduh salinan lengkap seluruh database SMP Negeri 1 Satui yang mencakup tabel Data Siswa, Data Guru, dan Log Kehadiran (Masuk & Pulang). Disarankan melakukan backup rutin setiap akhir bulan atau semester.

Pilihan Format File Backup:

• Format JSON (.json): Format standar sistem untuk proses Import / Restore tercepat & akurat.

• Format Excel (.xlsx): Berisi 3 Sheet sekaligus (Data_Siswa, Data_Guru, Log_Absen) yang bisa dibuka di Microsoft Excel dan juga mendukung proses Import kembali.

Import / Restore Semua Data

Pulihkan atau masukkan seluruh data dari file cadangan (.json atau .xlsx hasil backup). Anda dapat memilih untuk menggabungkan data baru atau menimpa (reset) seluruh isi database.
